# 완전제곱식 퍼즐

중학교 3학년 학생이 넓이 모델로 완전제곱식의 구조를 탐구하는 Streamlit 교육 앱입니다. 문제 `x² + 10x = 24`를 제시하고, `x²` 타일 1개, 가로·세로 `5x` 직사각형 각 1개, 넓이가 25인 정사각형 1개로 한 변이 `x + 5`인 정사각형을 완성합니다. 가로·세로 `4x`, `6x` 오답 직사각형과 넓이가 16, 36인 오답 정사각형도 보관함에 제공됩니다.

## 실행 방법

먼저 `uv`를 설치한 뒤 저장소 루트에서 다음 명령을 실행합니다.

```
uv sync
uv run streamlit run streamlit_app.py
```

조각을 드래그해 격자에 놓으면 현재 넓이 합이 갱신되고, `x²`와 두 직사각형을 놓으면 `x² + 10x = 24`가 표시됩니다. 조각은 겹쳐 놓을 수도 있으며, 겹치거나 빈틈이 있으면 큰 정사각형 완성으로 판정되지 않습니다. 네 정답 조각으로 큰 정사각형을 완성하면 넓이 합에 `x² + 10x + 25 = 24 + 25`가 나타납니다. **완전제곱식으로 바꾸기**를 누르면 넓이 합은 숨겨지고 등식과 `(x + 5)² = 49`, 해를 고르는 5지선다가 표시됩니다. 오답 조각은 보관함으로 드래그해 되돌릴 수 있습니다. 조각은 보관함과 판에서 같은 비율로 표시됩니다. **다시 시작**을 눌러 활동을 초기화할 수 있습니다.
