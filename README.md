# 완전제곱식 퍼즐

중학교 3학년 학생이 넓이 모델로 완전제곱식의 구조를 탐구하는 Streamlit 교육 앱입니다. 문제 `x² + 10x = 24`를 제시하고, 빈 퍼즐 판에 `x²` 타일 1개, 가로·세로 `5x` 직사각형 각 1개, 넓이가 25인 정사각형 1개를 배치해 한 변이 `x + 5`인 정사각형을 완성합니다. 조각을 배치할 때마다 현재 넓이의 합이 표시됩니다.

## 실행 방법

먼저 `uv`를 설치한 뒤 저장소 루트에서 다음 명령을 실행합니다.

```
uv sync
uv run streamlit run streamlit_app.py
```

보관함의 네 조각은 모두 퍼즐 판 바깥에서 시작합니다. 조각을 드래그해 격자에 놓고, **다시 시작**을 눌러 활동을 초기화할 수 있습니다. 완성하면 `x² + 10x + 25 = 24 + 25`, 즉 `(x + 5)² = 49`가 표시됩니다.
