# 완전제곱식 퍼즐

중학교 3학년 학생이 넓이 모델로 완전제곱식의 구조를 탐구하는 Streamlit 교육 앱입니다. 첫 문제 `x² + 10x = 24`를 풀고 정답을 확인하면 도전 문제 `x² + 8x = 9`를 풀 수 있습니다. 각 문제는 `x²` 타일, 가로·세로 직사각형, 알맞은 넓이의 정사각형을 배치해 완성합니다. 계수와 다른 크기의 직사각형 및 정사각형은 오답 조각으로 제공됩니다.

## 실행 방법

먼저 `uv`를 설치한 뒤 저장소 루트에서 다음 명령을 실행합니다.

```
uv sync
uv run streamlit run streamlit_app.py
```

조각을 드래그해 격자에 놓으면 현재 넓이 합이 갱신됩니다. 조각은 겹쳐 놓을 수도 있으며, 겹치거나 빈틈이 있으면 큰 정사각형 완성으로 판정되지 않습니다. 퍼즐 완성 후 **완전제곱식으로 바꾸기**를 누르면 넓이 합은 숨겨지고 완전제곱식과 5지선다가 나타납니다. 답을 고르고 **정답 확인**을 눌러 맞히면 풀이 과정과 **다른 문제 풀기** 버튼이 표시됩니다. 도전 문제를 완성하면 계수에 맞춘 풀이 과정과 해 선택이 표시됩니다. 오답 조각은 보관함으로 드래그해 되돌릴 수 있습니다. 조각은 보관함과 판에서 같은 비율로 표시됩니다. **다시 시작**을 눌러 현재 문제를 초기화할 수 있습니다.
